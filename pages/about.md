This collection features oral history interviews with Stanislaus State emeritus and retired faculty, retired staff, and alumni. It includes digitized interviews from as early as 1983 but most are from two history professors: 1) Dr. Nancy Taniguchi (who was at Stan State 1993-2010) and Dr. Jennifer Cullison (who has been at Stan State since 2022).  This project started in Fall 2026, when students in Dr. Cullison's graduate seminar in public history began the process of preparing transcripts and determining tags for the collection.  This project builds upon the work of student interviewers between 1983 and 2010 as well as more recent students since 2022 who have been creating summaries and transcripts for the old oral histories as well as recording new oral histories.


The collection uses the [Oral History as Data (OHD)](https://github.com/oralhistoryasdata/) framework, which is a static website generator that allows users to analyze and publish coded oral history or qualitative interview files. By turning transcriptions into tagged/coded CSV files, adding a list of filters, and creating a simple markdown file for each interview (to be included in the _transcripts collection), OHD will provide filterable transcripts and a color coded visualization for all transcripts included.
